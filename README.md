# Quick Side Nav

通常Webページ上で、複数のキーやマウスサイドボタンを別々のURLへ割り当てられるChrome拡張です。

例：

- `Q` キーでURL 1へ移動
- サイドボタンでURL 2へ移動
- `Ctrl + Shift + G` でURL 3へ移動

G HUB、Logicool Options+、AutoHotkeyなどの外部ツールは不要です。

## インストール

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. このリポジトリのフォルダを選択する

## 使い始める

1. 拡張機能アイコンをクリックする
2. 「入力監視」をONにする
3. 「設定を開く」を押す
4. 必要に応じてURLプリセットを追加する
5. 起動ルールを追加する
6. 各ルールに起動方法と移動先URLを設定して保存する
7. 通常Webページ上で登録したキーやサイドボタンを押す

既に開いていたページで動かない場合は、そのページを再読み込みしてください。

## 起動ルール

起動方法はルールごとに選べます。

- サイドボタン
- 戻る側のサイドボタン
- 進む側のサイドボタン
- 任意のキー

キーを使う場合は「キーを記録」を押して、使いたいキーを押してください。`Q` のような単独キー、`Ctrl + Shift + G` のような組み合わせキーを登録できます。

同じ起動方法を複数ルールに重複登録することはできません。

## URL

保存できるURLは `https://` または `http://` で始まるURLだけです。
URLは2,048文字以内で、`https://user:password@example.com/` のようにユーザー名やパスワードを含めることはできません。
初期URLは動作確認用の `https://example.com/` です。実際に使うURLへ変更して保存してください。

設定画面のURLプリセットに、よく使う移動先URLを保存できます。各ルールではプリセットを選ぶか、URLを直接入力できます。「プリセットに追加」を使うと、ルールへ入力済みのURLからすぐにプリセットを作成できます。

プリセットを選んだルールは、そのプリセットのURLに連動します。連動中のURLはルール側では読み取り専用になり、「プリセットを編集」または「直接入力に切り替える」を選べます。使用中のプリセットを削除しても、各ルールは最後に保存されたURLを直接入力として保持します。

## 動作対象と制約

- 通常Webページ上でのみ動作します
- `chrome://extensions` や `chrome://settings` などのChrome内部ページでは動作しません
- Chrome Web Storeや他の拡張機能ページなど、content scriptを注入できないページでは動作しません
- アドレスバー、タブバー、ブックマークバー上では動作しません
- iframe内では動作しない場合があります
- キー起動は、inputやtextareaなどの文字入力欄では誤操作防止のため動作しません
- ChromeやOSが予約しているショートカットは動作しない場合があります
- ページ側やブラウザ側の戻る・進む動作と競合する場合があります

## トラブルシューティング

### サイドボタンやキーで動かない

- 拡張機能アイコンをクリックし、「入力監視」がONになっているか確認してください
- 設定画面で起動ルールが保存されているか確認してください
- 通常Webページ上で確認してください
- ページ本文の上にマウスカーソルを置いて押してください
- キー起動の場合は、文字入力欄ではなくページ本文で押してください
- 拡張機能を読み込んだあとに開いていたページは再読み込みしてください

### 登録URLへ移動しない

- optionsページでURLが保存されているか確認してください
- `https://` または `http://` から始まるURLを入力してください
- popupの各ルールの「このタブで開く」で移動できるか確認してください

### Chrome内部ページで動かない

`chrome://extensions` や `chrome://settings` などの内部ページではcontent scriptが動作しません。通常のWebページで確認してください。

## Chrome Web Store用パッケージ

公開用ZIPはリポジトリ直下で次のコマンドを実行して作成します。

```powershell
./scripts/package-extension.ps1 -OutputDirectory dist
```

Chrome Web Storeのダッシュボードには、ZIPとは別に `store-assets` 内のスクリーンショットやプロモーション画像をアップロードします。

リリースブランチとGitHub Actionsによるデプロイ手順は [RELEASE.md](RELEASE.md) を参照してください。
