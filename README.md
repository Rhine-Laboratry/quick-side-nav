# Quick Side Nav

通常Webページ上でマウスのサイドボタンまたは設定したキーを押すと、現在のタブを登録URLへ移動するChrome拡張です。

G HUB、Logicool Options+、AutoHotkeyなどの外部ツールは不要です。

## インストール

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. この `quick-side-nav` フォルダを選択する

## 使い始める

1. 拡張機能アイコンをクリックする
2. 「起動監視」をONにする
3. 通常Webページを開く
4. ページ本文の上にマウスカーソルを置き、サイドボタンまたは設定したキーを押す

既に開いていたページで動かない場合は、そのページを再読み込みしてください。

## URLと起動方法を変更する

1. 拡張機能アイコンをクリックする
2. 「設定を開く」を押す
3. 移動先URLを入力する
4. 起動方法を「サイドボタン」または「キー」から選ぶ
5. キーを使う場合は「キーを記録」を押して、使いたいキーを押す
6. 保存する

保存できるURLは `https://` または `http://` で始まるURLだけです。

## 動作対象と制約

- 通常Webページ上でのみ動作します
- `chrome://extensions` や `chrome://settings` などのChrome内部ページでは動作しません
- Chrome Web Storeや他の拡張機能ページなど、content scriptを注入できないページでは動作しません
- アドレスバー、タブバー、ブックマークバー上では動作しません
- キー起動は、inputやtextareaなどの文字入力欄では誤操作防止のため動作しません
- ページ側やブラウザ側の戻る・進む動作と競合する場合があります

## トラブルシューティング

### サイドボタンやキーで動かない

- 拡張機能アイコンをクリックし、「起動監視」がONになっているか確認してください
- 設定画面で起動方法が正しいか確認してください
- 通常Webページ上で確認してください
- ページ本文の上にマウスカーソルを置いて押してください
- キー起動の場合は、文字入力欄ではなくページ本文で押してください
- 拡張機能を読み込んだあとに開いていたページは再読み込みしてください

### 登録URLへ移動しない

- optionsページでURLが保存されているか確認してください
- `https://` または `http://` から始まるURLを入力してください
- popupの「このURLを開く」で移動できるか確認してください

### Chrome内部ページで動かない

`chrome://extensions` や `chrome://settings` などの内部ページではcontent scriptが動作しません。通常のWebページで確認してください。
