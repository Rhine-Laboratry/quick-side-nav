Quick Side Nav Settings

Assign keys and mouse side buttons to different destination URLs on regular web pages. The extension does not work on Chrome internal pages or in the address bar. Reload pages that were already open if triggers do not respond.

URL presets

Save frequently used destinations and select them from any rule.

Trigger rules

Example: press Q for URL 1 and a side button for URL 2.

Two-tab coordination

Register different main and sub tabs in the popup. With Input monitoring on, F1 registers the main tab and F2 registers the sub tab. The trigger opens the sub URL, waits, then opens the main URL without changing focus.

Run key
R

F1 and F2 are reserved for registration while this feature is enabled. Input fields ignore the run key.

How to use

Turn on Input monitoring from the extension popup. On a regular web page, use a saved key or side button to navigate to its URL. Side-button rules may override the browser's Back or Forward action.
